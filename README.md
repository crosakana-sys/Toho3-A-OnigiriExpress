# おにぎりEXPRESS 公開手順

ファイルは4つです。

- `index.html` … お客さん用の注文ページ
- `admin.html` … 注文管理ページ(パスワードつき)
- `Code.gs` … Googleスプレッドシートに注文をためるスクリプト
- `README.md` … この手順書(GitHubに上げなくてOK)

## 1. スプレッドシートとスクリプトを用意する(Google)

1. Googleスプレッドシートを新しく作る(名前は「おにぎり注文」など)。
2. メニューの「拡張機能」→「Apps Script」を開く。
3. 最初から入っているコードを全部消して、`Code.gs` の中身を貼り付ける。
4. 一番上の `KEY` を、自分で決めたパスワードに書き換える(管理ページを開くときに使う。長めがおすすめ)。
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」を選ぶ。
   - 次のユーザーとして実行:**自分**
   - アクセスできるユーザー:**全員**
6. 「デプロイ」を押して、Googleアカウントの許可を進める(「安全ではないページ」と出たら、詳細から進む)。
7. 出てきた「ウェブアプリのURL」(`https://script.google.com/macros/s/…/exec`)をコピーする。

※ あとで `Code.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ、をやり直してください。

## 2. HTMLにURLを入れる

`index.html` と `admin.html` の両方で、下の文字を探して、手順1のURLに置き換えます(2つとも同じURL)。

```
PASTE_APPS_SCRIPT_URL_HERE
```

## 3. GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作る(Public。名前は `onigiri-express` など)。
2. 「uploading an existing file」から、`index.html` と `admin.html` をアップロードして「Commit changes」。
3. リポジトリの「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」。
4. 数分たつと、`https://ユーザー名.github.io/onigiri-express/` のようなURLが出る。
   - お客さん用:そのURL
   - 管理用:そのURLの最後に `admin.html` をつけたもの

## 4. 動作を確かめる

1. お客さん用ページで、テスト注文をしてみる。
2. スプレッドシートに `orders` というシートができて、1行増えていればOK。
3. 管理ページを開いて、パスワードを入れる。注文が時間ごと・具ごとに出ればOK。
4. テストが終わったら、スプレッドシートの `orders` シートの2行目以降を消してから本番へ。

## 知っておいてほしいこと

- 注文番号は、同じ日・同じ受け取り時間の中で、注文した順に 1, 2, 3… と付きます(11:00なら 1-1、1-2…、12:30なら 2-1、2-2…)。99を超えたら100、101…と続きます。
- 管理ページのURLとパスワードは、3-Aのメンバーだけに伝えてください。パスワードが分からない人は注文一覧を見られません。
- お客さん用ページの送信先URLは、ページのソースから分かります。いたずらで注文を送られる可能性はゼロではないので、当日は時々スプレッドシートを見て、おかしな注文があれば管理ページで削除してください。
- 「終了」にしたい日や時間があるときは、`index.html` を更新します(Claudeに頼めば書き換えます)。
